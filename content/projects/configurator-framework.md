One in-house pipeline behind five-plus real-time product configurators for luxury fashion and automotive brands.

## The problem

Every configurator used to start from zero. Same lighting debates, same export bugs, same deadline.

## What I built

A framework that takes a Blender scene and ships a configurator: materials, variants, camera rails and a Vue front end, with the 3D look locked before a single line of product code.
