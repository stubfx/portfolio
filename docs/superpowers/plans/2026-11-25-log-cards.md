# Log With Attachments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the home page's scroll-driven flight with one plain git log where each project is a commit with its cover attached, add the first subtle animations (once-only fade-ins, planet draw-in, CSS drift, cover-to-page morph, a faint background world per project and work entry), and finish the open launch items (Twitch copy, self-hosted fonts) within measured performance budgets.

**Architecture:** The home template renders a single `ol.log`. Project rows are entries plus an attachment link that reuses the cover art (with a new standalone planet layer, positioned by container-query units). Motion is CSS-first: one `IntersectionObserver` (`src/client/reveal.js`) hides only rows below the fold at startup and reveals each once; drift uses `animation-timeline: view()`. The flight engine, segments and ground overlay are deleted; the graph and vim keys find projects by `data-kind`.

**Tech Stack:** Node 22 built-ins (`node:test`), vanilla ES modules and CSS; Python Playwright 1.64.1 + Pillow (+ fonttools/brotli for the font recipe) in a venv outside the repo, driving the host's Chromium 156.

**Spec:** `docs/superpowers/specs/2026-11-25-log-cards-design.md` (extends `docs/superpowers/specs/2026-11-25-portfolio-design.md`), plus `docs/superpowers/specs/2026-11-26-worlds-design.md` for Task 4.

## Global Constraints

- **Version control:** `gitt` only (an alias for git). Never run `git`, not even read-only. Branch `feat/fluid-flight`, local commits only, never push. Each commit message ends with the committing model's own `Co-Authored-By:` line.
- **Weight:** zero-dependency build; home JS under 25 KB gzipped (`node scripts/budget.mjs dist`); fonts at most 120 KB, and that budget never moves.
- **Motion is CSS-first:** CSS transitions and animations plus one `IntersectionObserver`. No JavaScript scroll engine, no per-frame style writes from script, no scroll-jacking; scrolling stays native.
- **Nothing may be invisible:**
  - not before the script runs, not if it fails, not under reduced motion;
  - not to assistive tech or find-in-page;
  - not after a fast scroll, a jump, a hash link, a Tab, a reload or Back, and not in print.
- **Reveal limits:** a fade-in lasts at most 0.9 s, and any stagger is at most 0.3 s.
- **`prefers-reduced-motion: reduce`:** nothing hidden or moved (no fade-ins, drift, draw-in or hover lift); view transitions are instant fades.
- **Contrast:** WCAG 2.2 AA everywhere, AAA body text. The build's palette check and the e2e contrast checks stay green.
- **Performance budgets** (`test/e2e/perf.py --assert`, median of 3, full log sweep at 1280×800): dropped frames under 2% at 1× CPU and under 10% at 4×; zero site-forced layouts; no site script task over 4 ms at 1×.
- **Copy:** no em dashes.

### Task 3: Motion: once-only fade-ins, attachment effects, drift, hover

**Files:**
- Create: `src/client/reveal.js`, `src/styles/motion.css`
- Modify: `scripts/build.mjs` (`CSS_ORDER` appends `'motion'`), `src/client/main.js`, `src/client/graph.js` (dispatch `graph:go`)
- Test: `test/build.test.mjs`, `test/e2e/check.py`

**Interfaces:**
- Consumes: Task 1's row markup; Task 2's `.l-planet .sphere` and `.orbit` (with `pathLength="1"`).
- Produces: `startReveal(doc): { reveal(el: Element, instant?: boolean): void } | null`. It returns null and does nothing under reduced motion or without `IntersectionObserver`.
- Produces: `graph.go(i)` dispatches `doc.dispatchEvent(new CustomEvent('graph:go', { detail: { el: rows[n].el } }))` before scrolling.

Behaviour of `startReveal`:
- **Startup**, in one read pass over `.log > .row` then one write pass: rows whose top is at or below `innerHeight` get class `rv`. Rows above the fold are never touched, and CSS never hides anything on its own, so nothing can flash or stay hidden without the script.
- **Observer:** one `IntersectionObserver` with `rootMargin: '0px 0px -15% 0px'` and `threshold: 0`. On `isIntersecting` it adds `in` and unobserves.
- **Instant reveal** (`in` plus `now`, which disables transitions) on:
  - `focusin` inside an unrevealed row;
  - `graph:go`, for the row containing `detail.el`;
  - the `location.hash` target at startup and on `hashchange`;
  - `pageshow`, and the first `requestAnimationFrame` after startup, for every `.rv:not(.in)` row then intersecting the viewport (covers reload, Back and late scroll restoration);
  - the reduced-motion media query turning on: reveal all instantly.
- **Print:** `beforeprint` reveals all instantly. CSS `@media print` forces them visible as well.

`motion.css` (start from the spike's values; Luca tunes them later):
- **Rows:**
  - `.rv { opacity: 0; transform: translate3d(0, 18px, 0); }`
  - `.rv.in { opacity: 1; transform: none; transition: opacity .9s cubic-bezier(.2,.7,.2,1), transform .9s cubic-bezier(.2,.7,.2,1); }`
  - `.rv.now { transition: none; }`
- **Attachment effects:** under `.rv:not(.in)`:
  - `.pc-att .sphere` is at `opacity: 0` and `scale(.86)` (`transform-box: fill-box; transform-origin: center`);
  - `.orbit` has `stroke-dasharray: 1; stroke-dashoffset: 1`.
  - Under `.rv.in` they transition to rest: sphere over 1.6 s with a .15 s delay, orbit over 2.6 s with a .35 s delay.
- **Drift:** inside `@supports (animation-timeline: view())` and `@media (prefers-reduced-motion: no-preference)`, these animate with `linear both` on `animation-timeline: view()`:
  - `.pc-att .l-back`: translateY 6% → −6%, scale 1.08;
  - `.pc-att .l-planet`: translate 8% → −8%;
  - `.pc-att .l-word span`: translateX 8% → −8%.
- **Hover and focus** (`.pc-att:hover`, `:focus-visible`): border `color-mix(in oklab, var(--p-accent) 70%, transparent)`, `translate3d(0, -2px, 0)`, chip arrow `translateX(5px)`, transitions .4–.5 s.
- **Reduced motion and print:**
  - `@media (prefers-reduced-motion: reduce)` and `@media print`: `.rv` is opacity 1 with no transform and no transition, and the sphere and orbit are at rest.
  - Reduced motion also turns off drift and hover lift.
