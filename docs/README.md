# Docs

The build contract for lucamolluso.com. Read in this order:

1. **[SPEC.md](SPEC.md)**: what we are building and why. Principles, decisions, scope, open questions, launch checklist.
2. **[DESIGN.md](DESIGN.md)**: the visual system. Themes (official Catppuccin; day by default, with pure black text), type, layout, visible syntax, components, grain, motion, accessibility.
3. **[CONTENT.md](CONTENT.md)**: how to write the site. The Markdown you can use, page formats, the case format, assets, voice.
4. **[BUILD.md](BUILD.md)**: how it is built. No framework, repo layout, renderer, outputs, git history, agent layer, theme switch, grain, 3D viewer, budgets, tests, deploy.

**Reference:** `prototype/index.html` (open it in a browser, no server needed) implements the design and the renderer with sample content. Where the prototype and these docs differ, the docs win.

**Versions:** docs v1, Nov 27, 2026. They replace the single-file SPEC v1 to v5; the history of those decisions is in git.
